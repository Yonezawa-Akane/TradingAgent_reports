# TradingAgent Reports

An archive of research reports generated by TradingAgent, organized by stock ticker and research date.

## Directory structure

```text
<TICKER>/
└── <YYYY-MM-DD>/
    └── reports/
        ├── final_trade_decision.md
        ├── trader_investment_plan.md
        ├── investment_plan.md
        ├── fundamentals_report.md
        ├── market_report.md
        ├── news_report.md
        └── sentiment_report.md
```

Reports come from TradingAgents' `results/<TICKER>/<YYYY-MM-DD>/reports/`. Preserve filenames and content verbatim, archiving only the human-readable Markdown reports. Runtime logs and caches remain in the source directory.

Start with `final_trade_decision.md` for the final conclusion, then read `trader_investment_plan.md` for the trading plan and `investment_plan.md` for the research conclusion. Consult the other analyses as needed.

Use the research date. Preserve differing same-day versions in `<YYYY-MM-DD>_HHMMSS` directories, using the local archive time for the suffix. Keep original research unchanged; record corrections in separate dated notes.

## Contributing

To contribute reports, corrections, or documentation, fork this repository and open a Pull Request targeting this repository's `main` branch for maintainer review. This repository maintains only `main`.

Use a short PR title describing the action and scope, such as `Add TSLA research — 2026-09-07`. Fill in the bilingual [PR template](.github/pull_request_template.md): check the purpose, explain what changed and why in 1–3 sentences, and list the affected tickers/dates or file paths. Responses may be in Chinese or English.
